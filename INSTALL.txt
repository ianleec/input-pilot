Input Pilot 1.1.1

系统：macOS 13 或更新版本；包含 Apple Silicon 与 Intel 两种架构。

安装：
1. 将 Input Pilot.app 拖到旁边的 Applications（应用程序）文件夹。
2. 从“应用程序”打开“Input Pilot”，菜单栏出现“IP”。
3. 在系统设置 → 键盘 → 输入法中启用“简体拼音”和“繁体拼音”。
4. 在工具内选择“繁体拼音”，点击“添加应用…”，选中需要繁体的应用。
5. 未配置应用默认简体；删除规则恢复默认简体。关闭或最小化设置窗口后继续运行。

这份安装包使用本地临时签名，未做 Apple Developer ID 签名和公证。
在其他 Mac 上首次打开可能被 Gatekeeper 拦截。如信任此来源，可依据 macOS 提示，在“系统设置 → 隐私与安全性”中明确允许；不要关闭系统整体安全保护。

首次发布仅在当前 Apple Silicon / macOS 26.6.2 真机验收；Intel 和 macOS 13 为构建目标，未进行对应真机验证。

隐私：
纯本地处理，无账号、服务器、遥测或第三方依赖。
App Sandbox 未授予任何网络权限，系统拒绝联网。
仅读取前台应用标识和本地输入法信息，不读取按键、输入内容、剪贴板或窗口标题。
配置保存在当前用户本机的应用沙盒中，不使用 iCloud 同步。
工具本身的无联网限制不代表系统输入法或其他软件也被禁止联网。

升级：先从菜单栏退出旧版本，再用新 App 替换。保持相同 Bundle ID，用户规则可继续使用。
旧名称“简繁随行 / PinyinPilot”升级时，请移除旧 App，仅保留 Input Pilot.app，避免同时运行。原配置标识保留用于兼容，不需重新添加规则。
开机启动：如需要，可手动在系统设置 → 通用 → 登录项中添加本应用。
卸载：退出后将 App 移入废纸篓。配置默认保留在本地沙盒。
